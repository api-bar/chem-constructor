# Химический конструктор «атомы + связи» — v1.0

> **EN:** Printable molecular model kit "atoms + bonds" (tested on Bambu Lab A1). Atoms are balls with keyed sockets at real valence angles;
> bonds are rods with twisted keys whose profile encodes bond order (single / double / triple). Scale 90 mm/Å, real bond lengths and angles.
> 20 assembled molecules (H₂O, CH₄, ethanol, acetic acid, 9 amino acids, Gly-Gly dipeptide…), per-color plates, OpenSCAD source.
> Print `04_tester/00_test_prism_and_keys.3mf` first. License: [CC BY-NC-SA 4.0](LICENSE).

Детский/учебный конструктор молекул для 3D-печати (Bambu Lab A1). Атомы — шары с пазами под правильными валентными углами,
связи — стержни с винтовыми ключами. Тип паза кодирует **кратность связи** (одинарная / двойная / тройная), цвет — элемент (CPK).
Масштаб 90 мм/Å (пресет `toddler`), длины связей и валентные углы — реальные.

> **Что в репозитории.** Здесь исходники (`00_source/`), документация и PNG-превью. STL, 3MF, GLB и USDZ в git не хранятся —
> они лежат в ассетах релиза v1.0. Как получить полную папку набора — см. [docs/RELEASE.md](docs/RELEASE.md).

## Детали (01_components)

| Атомы | Пазы |
|---|---|
| **C** углерод, Ø56 | 8 пазов: 4 одинарных (тетраэдр), 2 двойных (180° друг к другу), 1 тройной — все гибридизации на одном шаре |
| **N** азот, Ø52 | 3 одинарных, паз заглушки неподелённой пары, 1 тройной (напротив заглушки) |
| **O** кислород, Ø52 | 2 одинарных (104,5°), 1 двойной; неподелённые пары — бугорки |
| **H** водород, Ø40 | 1 одинарный |
| заглушка | закрывает паз неподелённой пары азота |

Связи: одинарные C–C, C–H, C–O, C–N, N–H, O–H, H–H (профиль ключа 18×6); двойные C=C, C=O, O=O (28×7); тройные C≡C, C≡N, N≡N (26×10).
Чужой ключ в паз не входит. Длина каждой связи — по реальной длине (одинарные O–H, C–H, C–C не взаимозаменяемы по длине).
Цвет связей: оранжевые — полярные, серые — неполярные.

### Пазы углерода (как их различить)
Углы проверены по модели:
- **тройной** паз — самый толстый (26×10);
- **T1** — одинарный строго **напротив тройного** (180°);
- **Д1** — двойной паз рядом с парой одинарных **T2, T3** (по 55°);
- **Д2** — второй двойной, напротив Д1; рядом с ним одинарный **T0** (50°);
- **T2 / T3** — пара одинарных у Д1 (выбор между ними задаёт L/D у аминокислот).

Гибридизации: **sp³** — T0, T1, T2, T3 · **sp²** — T0, T1 + Д1 (плоская: этилен, карбоксил, амид) · **sp (=,=)** — Д1 + Д2 (CO₂) · **sp (−,≡)** — T1 + тройной (ацетилен, HCN).

## Механизм соединения
Витой ключ на конце связи ввинчивается в винтовую щель паза **по часовой стрелке** (правый винт), ~⅓ оборота.
Фиксация: **клин** в губе паза (ключ конусный) + **защёлка** — бугорок 0,9 мм на лопасти и лунки в обеих стенках щели (связь садится любой стороной).
Фаза двойного паза углерода выставлена так, что два sp²-углерода через C=C лежат в одной плоскости (этилен плоский).

## Печать (Bambu Studio / A1)
- **Атомы, заглушки** — PLA, плоскостью (с гравировкой) вниз, поддержки **выкл.** Слой 0,2, стенки 3, заполнение 15 % (grid).
  Предупреждение «floating regions» у углерода — ≤1 мм² у устья нижнего паза, печатается без поддержек.
- **Связи** — PETG, **стоя** (уже так на пластинах), поддержки выкл., brim 5 мм, 4 стенки / 100 %.
- Импорт: File → Import → «Import geometry only». Цвета в 3MF проставлены для удобного назначения филамента.
- Сначала напечатать `04_tester/00_test_prism_and_keys.3mf` и проверить посадку; настройки зазоров — в `00_source/chem_constructor.scad` (`snap_clr`, `tip_clr`, `det_h`).

## Как собрать конкретную молекулу
1. Откройте `02_molecules/<молекула>/README.md` — там список деталей и пластины этой молекулы по цветам (`plates/`).
2. Напечатайте пластины (по одной на филамент).
3. Соберите по шагам: от центрального атома наружу. Каждый шаг: «связь X — в паз Y атома Z; на другой конец — атом пазом W».
4. Сверьтесь с `.usdz` на телефоне (AR) или `.glb` в Blender.
5. Для аминокислот проверьте хиральность (правило в README молекулы).

## Что ещё можно собрать из этих деталей
**Аминокислоты (только C, H, N, O, без колец и без C=N):** проверены сборкой — Gly, Ala, Val, Ser, Asn, **Thr, Leu, Asp, Lys**.
Также собираются (та же химия, не проверял отдельно): **Ile, Glu, Gln**.
**Нельзя сейчас:** Cys, Met (нужна сера S); Phe, Tyr, Trp, His, Pro (кольца); Arg (группа C=N — у азота нет двойного паза).
**Сложные эфиры:** да — проверен метилацетат CH₃COOCH₃; этилацетат, метилформиат и т. п. собираются так же.
**Олигопептиды:** да — проверен Gly-Gly. Цепочки из 3–5 остатков возможны (связи C–N, C=O, N–H есть), но длинные — громоздкие (>40 см).

## Ограничения (кандидаты на рефакторинг)
1. **Кольца не замыкаются.** Винт фиксирует двугранный угол каждой связи, поэтому конформация молекулы единственная. Кинематическая проверка
   цепочки из 6 углеродов: конец либо уходит на 416–571 мм, либо упирается в начало (15 мм) при нужных 139 мм. Нужна свобода вращения вокруг
   одинарной связи (например, 3-заходный ключ с шагом 120° или вращающаяся втулка).
2. **Азот всегда пирамидальный** — амидный N (пептидная связь, Asn) в реальности плоский.
3. **Нет двойного паза у азота** (C=N, N=O) и нет серы, фосфора, галогенов.
4. **Пазы углерода не подписаны** — различаются только по положению; полезна гравировка меток у пазов.
5. Длины одинарных связей разные — набору нужно много типов стержней; возможен вариант «универсальная одинарная» для младших.

## Проверки, через которые прошла каждая деталь
герметичность сетки, одно тело, отсутствие послойных «островов» (печать без поддержек), профиль зазора ключ↔паз по глубине,
булева посадка каждой пары «паз ↔ конец связи», сборка молекул без пересечений, проверка хиральности L-аминокислот.

## Проверено печатью
Напечатаны на Bambu Lab A1 и проверены вручную: атомы C, O, H, N; связи одинарные, двойные и тройные.
Из напечатанных деталей собраны H₂, H₂O, CH₄, CO₂, формальдегид H₂CO, муравьиная HCOOH и уксусная CH₃COOH кислоты (фото — на страницах набора на площадках моделей).
