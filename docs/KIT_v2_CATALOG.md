# Конструктор «атомы + связи» v2 — описание набора, компоненты и каталог молекул

Состояние: v2.0-beta5, 2026-10-18. Масштаб **90 мм на 1 Å**: расстояние между центрами атомов = реальная длина связи × 90.
Углы между пазами — реальные валентные. Цвета атомов — CPK. Все детали печатаются на Bambu Lab A1 (стол 256×256 мм).

---

## 1. Как устроен набор

Набор состоит из **атомов** (шары с пазами) и **связей** (стержни с ключами на концах). Тип паза и ключа кодирует **кратность связи**:
чужой ключ в паз не входит, поэтому собрать «неправильную» молекулу нельзя.

| Кратность | Ключ на связи | Паз в атоме | Как соединять |
|---|---|---|---|
| **Одинарная** | цилиндр Ø15, длина 16,3 мм, у основания 3 полусферических бугорка 0,8 мм через 120° | круглое отверстие Ø15,6; от устья идут 3 входные бороздки; перед кольцевой канавкой (глубина 4,5 мм) их дно поднято — **губа** с натягом 0,3 мм | совместить бугорки с бороздками, нажать до щелчка. Дальше связь **свободно вращается** вокруг своей оси. Вынуть — снова совместить с бороздками и потянуть |
| **Двойная** | витой ключ, сечение **линза** 28×7 мм, правый винт, конус к основанию, бугорок 0,9 мм | винтовая щель-линза с винтовым входным каналом и губой | ввинтить по часовой стрелке (если смотреть на атом) ~⅓ оборота до щелчка. 2 положения (через 180°), угол поворота фиксирован — как у настоящей двойной связи |
| **Тройная** | витой ключ, сечение **треугольник Рёло** 15 мм, 1 бугорок | винтовая щель-Рёло, 3 входных канала с губой | ввинтить до щелчка, 3 положения (через 120°) |

Фиксация везде одинаковая по принципу: **клин** (конус ключа зажимается в конической щели) + **защёлка** на сжатии пластика (бугорок проходит губу и падает в канавку/лунку). Пружинящих элементов нет.

Длина каждой связи — реальная для своей пары атомов (например, C–C 1,54 Å → 139 мм между центрами), и на стержне она **выгравирована в ангстремах**.

## 2. Атомы

Радиусы подобраны так, чтобы все пазы поместились без пересечений; шар срезан плоскостью снизу (для печати), на срезе гравировка: символ, валентность, заряд ядра, атомная масса.

| Атом | Цвет | Ø, мм | Пазы | Какие геометрии даёт |
|---|---|---|---|---|
| **H** водород | белый | 44 | 1 одинарный | концевой атом |
| **C** углерод | чёрный | 56 | **8 пазов**: 4 одинарных (тетраэдр T0–T3), 2 двойных (Д1, Д2 — напротив друг друга), 1 тройной (напротив T1) | **sp³** — T0,T1,T2,T3 (метан, алканы) · **sp²** — T0,T1 + Д1, плоский (этилен, карбонил, карбоксил, амид) · **sp (=,=)** — Д1 + Д2 (CO₂, аллен) · **sp (−,≡)** — T1 + тройной (ацетилен, нитрилы) |
| **O** кислород | красный | 52 | 2 одинарных под 104,5°, 1 двойной; неподелённые пары — бугорки | вода, спирты, эфиры (2 одинарных); карбонил, O₂ (двойной) |
| **N** азот | синий | 52 | 3 одинарных (пирамида, 107°), паз заглушки неподелённой пары, 1 тройной (напротив заглушки), **1 двойной** (sp²: 120° к T0, в плоскости T0–T1) | аммиак, амины, амиды (3 одинарных + заглушка); N₂, нитрилы (тройной); N=O, имины, азо (двойной + T0, заглушка в T1) |
| **заглушка неподелённой пары** | розовый/белый | — | круглый ключ одинарного типа | закрывает пустой одинарный паз азота (или любой другой) — показывает неподелённую пару |

Как различить пазы углерода: тройной — самый толстый; T1 — строго напротив тройного; Д1 — двойной рядом с парой одинарных T2, T3; Д2 — напротив Д1, рядом с ним T0. Выбор между T2 и T3 задаёт L/D-форму аминокислот.

|---|---|---|---|---|
| **F** фтор | светло-зелёный | 44 | 1 одинарный | |

## 3. Связи

Стержень Ø12 мм, ключи на концах по типу пазов. Цвет (рекомендация): **оранжевые** — полярные (C–O, O–H, N–H, C–N, C=O, C≡N, N=O, S=O, P=O), **серые** — неполярные (C–C, C–H, H–H, C=C, C≡C, N≡N, O=O), **зелёные** — универсальные.

### 3.1 Одинарные (`bonds_rigid_labelled/`, с гравировкой длины)

| Связь | Å | Между центрами, мм | Видимый стержень, мм | Для чего |
|---|---|---|---|---|
| C–C | 1,54 | 139 | 83 | алканы, боковые цепи |
| C–O | 1,43 | 129 | 75 | спирты, эфиры, кислоты |
| C–N | 1,47 | 132 | 78 | амины, амиды, аминокислоты |
| C–H | 1,09 | 98 | 48 | |
| N–H | 1,01 | 91 | 43 | |
| O–H | 0,96 | 86 | 38 | |
| H–H | 0,74 | 67 | 23 | только H₂ |

Каждая одинарная есть в трёх исполнениях: **жёсткая** (гравировка длины), **гибкая spring**, **гибкая slots** — ключи одинаковые, отличается только середина стержня (см. раздел 4).

### 3.2 Универсальные одинарные (без гравировки)

| | Стержень | Между центрами с атомами | Заменяет | Погрешность |
|---|---|---|---|---|
| **U1** | 79 мм | C–C 135 (1,50 Å), C–O 133 (1,48), **N–O 131 (1,46)**, **N–N 131 (1,46)**, **O–O 131 (1,46)**, P–O 136 (1,51), C–F 129 (1,43) | C–C, C–O, а также одинарные **N–O, N–N, O–O, P–O**, которых нет отдельными деталями | 3–6 % |
| **U2** | 43 мм | C–H 93 (1,03 Å), N–H 91 (1,01), O–H 91 (1,01), **H–F 87 (0,96)** | C–H, N–H, O–H, **H–F** | до 6 % |

U1 важна не только как «упрощение»: с ней собираются пероксид водорода, гидразин, азотистая кислота, нитросоединения, фосфорная кислота — молекулы с одинарными связями N–O, N–N, O–O, P–O.

| S=O | 1,43 | SO₂ |

| C≡C | 1,20 | ацетилен, алкины |

### 3.5 Универсальные двойные и тройная (без гравировки)

Ключи те же (линза / Рёло), отличается только длина стержня — среднее по группе. Посадка проверена булевой сборкой: UD2 в O 0,48 мм³, в C 0,79, в N 0,43; UT в C 0,04, в N 1,43 (как у специальных).

| | Стержень | Заменяет | Погрешность |
|---|---|---|---|
| **UD1** | 63 мм | C=C (1,32 вместо 1,34 Å), C=N (1,30 вместо 1,28) | ≤2 % |
| **UD2** | 55 мм | C=O (1,21), O=O (1,19 вместо 1,21), N=O (1,19 вместо 1,15), N=N (1,19 вместо 1,25) | ≤5 % |
| **UT** | 50 мм | C≡C (1,18 вместо 1,20), C≡N (1,16), N≡N (1,13 вместо 1,10) | ≤3 % |

Итого универсальных связей пять: U1, U2 (одинарные), UD1, UD2 (двойные), UT (тройная). Из них одних можно собрать любую молекулу каталога с погрешностью длин до 6 %, а специальные связи с гравировкой показывают точные длины.

## 4. Гибкие связи (одинарные)

Гибкий участок — 70 % длины стержня, снаружи Ø12, на концах 45°-пробки (печать стоя без мостов). Два финальных варианта, выбор — по печати:

| Вариант | Устройство | Идея прочности |
|---|---|---|
| **spring** | сердечник Ø3 + 5 лент 2×2 по правой спирали 45° + 5 тонких лент 1,4×1,4 по левой спирали на том же радиусе, сплавлены в перекрестьях (решётка-стент) | излом требует разрыва нескольких лент; нагрузка распределена по решётке; сердечник держит длину |
| **slots** | трубка стенка 1,5 с кольцевыми прорезями 150° в шахматном порядке (скруглённые концы) + внутри 3-заходная спираль 1,6×1,6 на сердечнике Ø4, соединённая с трубкой только через торцы | внутренняя спираль задаёт плавную кривизну и держит растяжение; при трещине перемычки связь не распадается |

Двойные и тройные связи — жёсткие (поворот вокруг них и так зафиксирован ключом).

## 6. Каталог молекул

Обозначения статуса:
- **✅** собрана из печатных STL и проверена булевой сборкой (пересечений нет);
- **✔** собирается из деталей набора точно (нужные пазы, углы и связи есть), сборкой пока не проверялась;
- **≈** собирается, но с универсальной связью или с приближённым углом — указано, что именно;
- **⟳** кольцо: геометрически замыкается, нужна проверка сборкой (ошибка замыкания);
- **✖** не собрать — указано, чего не хватает.

Состав: атомы / связи. Заглушка (з) ставится в свободный паз азота.

| диазен HN=NH, азометан | | ✔ новая связь N=N |
| гуанидин, аргинин | | ✔ через C=N |

### 6.5 Аминокислоты и пептиды

Все L-аминокислоты собираются в S-конфигурации (правило в README v1: H у Cα от себя, N → COOH → боковая цепь против часовой стрелки).

| Аминокислота | Статус |
|---|---|
| Gly, Ala, Val, Leu, Ile, Ser, Thr, Asn, Gln, Asp, Glu, Lys | ✔ (Ala собрана в v2; Gly, Val, Ser, Asn, Thr, Leu, Asp, Lys — в v1, в v2 те же пазы) |
| Arg | ✔ через новую C=N |
| Phe, Tyr | ⟳ бензольное кольцо |
| Pro | ⟳ 5-членное кольцо — вероятно, не замкнётся жёсткими стержнями |
| Met, Cys | ✖ нет C–S, S–H |
| Trp, His | ✖ 5-членные гетероциклы |
| Gly-Gly, Ala-Gly, трипептиды | ✔ пептидная связь: C=O в Д1, C–N, N–H (+з) |

### 6.6 Что можно показать благодаря v2 (чего не могла v1)

- **Конформации**: поворот вокруг одинарных связей — заслонённый/заторможенный этан, гош/анти бутан, кресло циклогексана.
- **Кольца**: циклогексан (проверен), бензол и пиранозы (проверить).
- **Жёсткость кратных связей**: C=C не крутится (цис/транс-бутен-2 — две разные молекулы), C–C крутится.
- **Гибкость связи**: деформация и возврат (spring/slots).
- **Азот sp²**: NO, нитрозо-, азотистая кислота (плоская), имины, азосоединения.
- **Длины связей**: гравировка в Å позволяет сравнивать C–C 1,54 / C=C 1,34 / C≡C 1,20 прямо на деталях.
