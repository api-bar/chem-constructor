# Пластины минимального набора v2 — связи с маркировкой длины, азот с двойным пазом

## Что изменилось
1. **Маркировка.** На каждом стержне с двух сторон выгравирована длина связи в ангстремах («0.96 Å», «1.54 Å»…), глубина 1 мм, шрифт DejaVu Sans Bold 4,5 мм.
   Одинарные связи разной длины теперь различаются по надписи. (У гибких spring/slots середина — решётка, там надписи пока нет.)
2. **Азот получил двойной паз** `N_D = [-0.866, 0, -0.5]`: 120° к одинарному T0, 130,5° к T1 (сюда — заглушка неподелённой пары), 54,9° к T2/T3, 125° к тройному.
   T0, T1 и N_D лежат в одной плоскости — sp²-азот (R–N=O, HO–N=O, имины). Фаза паза `N_D_PHASE = 66` подобрана так, что
   двугранный угол T0–N=O–(одинарный O) = 0,0°: HO–N=O собирается **плоским**, как настоящая азотистая кислота.
   Посадка линзы в паз азота: 0,71 мм³ (как у кислорода 0,59 мм³), N и O в сборе NO не пересекаются.
3. **Связь N=O** — обычная двойная (линза с обеих сторон), 1,15 Å, `bond_NdO`. Гибридная «Рёло + линза» удалена.
   NO собирается как N + N=O + O; одинарный паз T0 у азота остаётся пустым — это неспаренный электрон радикала NO.
