# Публикация v2.0-beta5: что где лежит

Ветка `v2` в GitHub — витрина и исходники второй версии (OpenSCAD и скрипты). Печатные и 3D-файлы на GitHub **не публикуются**: ни в git, ни в GitHub Release.
Они входят в комплект v2, который распространяется отдельно (площадка продажи по бизнес-плану), и лежат только в локальной рабочей папке автора.

## Что в git (ветка `v2`)

| Что | Где |
|---|---|
| Параметрический исходник `chem_constructor.scad` (OpenSCAD); скрипты сборки и проверки: `chemlib.py`, `molecules.py`, `assemble3.py`, `seat_cache_v2.json`, `pipeline/` | `00_source/` |
| Документация: README набора, `STATUS.md`, каталог молекул и описание механизма | корень, `docs/`, `06_v2_test_plates/README.md`, `07_v2_new_elements/README.md` |
| PNG-превью: 10 сборок молекул, разрезы гибких связей, раскладка новых элементов | `02_molecules/*/`, `05_flex_bonds/`, `07_v2_new_elements/` |
| `LICENSE`, `.gitignore`, `make_kit_archives.sh` | корень |

`.gitignore` — белый список: `*.md`, `*.py`, `*.scad`, `*.json`, `*.sh`, `LICENSE` и PNG из перечисленных папок. Всё остальное, что лежит в рабочей папке, в коммиты не попадает.

и пластина `02_v2_bonds_rigid_19_…` (заменена `02_v2_bonds_rigid_22_…`).

## Архивы комплекта
`sh make_kit_archives.sh` из корня ветки `v2` собирает шесть zip в `dist/` (около 116 МБ, в git не попадают). Пути внутри архивов совпадают
со структурой набора: распаковка всех шести в одну папку даёт полную папку. Это заготовка для загрузки на площадку продажи; состав стартового и полного комплекта (по бизнес-плану) собирается из них отдельно.

Что печатать первым покупателю: `04_tester/00_v2_prism_keys.3mf` — проверка щелчка, вращения и взаимного исключения ключей.

## Тег
Тег с датой на ветке — подтверждение приоритета авторства (`docs/ops/release-tags.md` в репозитории планирования). GitHub Release с файлами не создаётся.

```
git tag -a v2.0-beta5 -m "v2.0-beta5 $(date +%Y-%m-%d)" v2
git push origin v2 v2.0-beta5
```

Содержимое ветки — по [LICENSE](../LICENSE) в её корне. Файлы комплекта (STL, 3MF, GLB, USDZ) покупатель получает на условиях личной лицензии v2; коммерческое использование — по отдельной коммерческой лицензии.
