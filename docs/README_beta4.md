Без пружинящих элементов — только сжатие пластика на губе. Взаимное исключение: цилиндр Ø15 не входит в линзу (7,9) и Рёло (вписанная 13,5); Рёло 15 не входит в круглое 15,6? — **входит с зазором 0,6 → см. «известные вопросы»**; линза не входит никуда, кроме своего.
Водород увеличен до Ø44 (стенка у устья круглого паза 1,5 мм). Стержни: шейка Ø7 на 70 % длины — гнутся и возвращаются (PETG).

## Проверено по STL (булевы проверки)
- одинарная в водороде: посажена — 0 мм³ при любом повороте (свободное вращение); ход по бороздкам — 0 до губы, 0,9 мм³ на губе (0,3 мм × 3 бугорка), затем 0; мимо бороздок — 2,4 мм³ (упор);
- линза в кислороде 0,6 мм³ (огранка); вывинчивание O=O по спирали: 0 мм³ везде, кроме губы (0,3 мм³); Рёло в азоте: по спирали ≤1,65 мм³ на губе, затем 0;
- **циклогексан замыкается точно (0,0 мм)**, 36 деталей, без столкновений — `02_molecules/cyclohexane.glb`; также вода, метан, этилен, CO₂, ацетилен, аммиак;
- 21 деталь герметична, одно тело; острова: углерод 2 (9,9 мм² — крыша винтового канала у устья паза, смотрящего вниз; 1,7), азот 3×0,5, призма 4×2,6 — потолки борозд/каналов в наклонных пазах; для углерода включить «Support critical regions only».

## Известные вопросы (проверить в пластике)

2. Усилие на губе (`peg_lip` 0,9 → натяг 0,3) и удержание (`peg_bump` 0,8).
3. Гибкость шейки Ø7 (`rod_neck_d`), тестер 02.

## Гибкие связи — кандидаты (05_flex_bonds)
Параметр `FLEX` в SCAD: `"neck"` | `"bellows"` | `"slots"` | `"spring"`. Гибкий участок — 70 % длины стержня, Ø12 снаружи, 45°-пробки на концах (печать стоя любым концом вверх).

| Тип | Устройство | Ожидание |
|---|---|---|
| neck | утонение до Ø7 (текущее) | умеренно гнётся, самый прочный |
| bellows | сильфон: стенка 1,2, шаг 4, шевроны 45° | большой упругий изгиб, длина не меняется, хорошая кручение |
| slots | трубка стенка 1,5 с кольцевыми прорезями 150° в шахматном порядке | гибкость задаётся перемычками; строже выглядит |
| spring | 3 ленты 2×2 по спирали 45° вокруг сердечника Ø4 | изотропный изгиб, «пружинный» вид; сердечник держит длину |

`03_v2_flex_variants_test.3mf` — четыре C–C (neck/bellows/slots/spring) + O–H сильфон и пружина, стоя, 150×16×115 мм, PETG, без поддержек.
`flex_variants.png` — разрезы. Все варианты герметичны, одно тело, 0–1 островок (сильфон/пружина ≤0,3 мм²).
Оба варианта spring и slots остаются в наборе; фиксировать один `FLEX` до релиза не требуется.

### Раскладка для теста гибкости — две пластины
**03 (стоя, без поддержек).** Слои поперёк оси: самая точная геометрия ключей и складок, но изгиб нагружает межслойную связь.
Brim 8 мм (столбики 115 мм), «Slow down for overhangs» вкл.
**04 (лёжа, с поддержками).** Слои вдоль оси — стержень на изгиб в 2–3 раза прочнее, именно так стоит печатать гибкие связи, если
стоячие будут трескаться. Настройки: Enable support ✓, Type tree(auto), On build plate only ✓, Threshold 40°,
Support/raft interface — PLA (если есть AMS) или Top Z distance 0,25 мм; после снятия поддержек пройти ключи шкуркой 600.
Поддержки лягут под сильфон и ленты пружины, под нижние бугорки одинарного ключа и под низ линзы/Рёло.
Сравнивать: одинаковый тип стоя vs лёжа — где трещина при изгибе до 40°, где остаточная деформация.

> Исправление: в первых версиях пластин O–H «сильфон» и «пружина» были гладкими стержнями (порог гибкости 40 мм при длине стержня O–H 38,4 мм). Порог для гибких типов снижен до 24 мм (`flex_min_len`), пластины и STL пересобраны; каждая O–H имеет 1 островок ≤5 мм² (кончик складки/торец пробки).
