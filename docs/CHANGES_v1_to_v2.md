# Химический конструктор «атомы + связи»: отличия v2 от v1

Состояние на 2026-10-18. v1.0 — выпущенная версия. v2 — в разработке (beta5), релиз заблокирован до выбора гибкой связи по результатам печати.
**Детали v1 и v2 несовместимы между собой:** у них разные ключи и пазы.

Общее для обеих версий: масштаб 90 мм/Å, реальные валентные углы, цвета CPK (C чёрный, O красный, N синий, H белый), OpenSCAD-исходник
с пресетом `toddler`, булева проверка посадки каждой пары «паз ↔ ключ» и сборок молекул без пересечений.

## 1. Крепление связь ↔ атом (главное отличие)

| | v1 | v2 |
|---|---|---|
| Одинарная связь | витой ключ 18×6, винтовая щель; ввинчивается на ⅓ оборота, клин + защёлка | **цилиндр Ø15** с 3 бугорками у основания; круглый паз-байонет с 3 входными бороздками, губой и кольцевой канавкой на глубине 4,5 мм |
| Вращение одинарной связи | нет: винт фиксирует двугранный угол | **свободное** после щелчка — можно поворачивать фрагменты молекулы |
| Двойная связь | витой ключ 28×7 (стадион) | витой ключ, сечение **линза** 28×7, 2 положения (180°) |
| Тройная связь | витой ключ 26×10 | витой ключ, сечение **треугольник Рёло** 15, 3 положения (120°) |
| Защёлка | бугорок 0,9 мм на лопасти + лунки в стенках щели | та же идея, но без пружинящих элементов: **губа с натягом 0,3 мм**, проходится на сжатии пластика; у винтовых ключей — винтовой входной канал с губой |
| Клин у кончика | есть | сохранён для линзы и Рёло |
| Взаимное исключение | чужой ключ не входит в паз | сохранено; открытый вопрос — Рёло 15 в круглом пазу Ø15,6 (запас 0,4 мм, при необходимости Рёло 17) |

Следствие: **в v2 замыкаются кольца** (циклогексан собирается с ошибкой 0,0 мм), в v1 кольца собрать нельзя.

## 2. Атомы

| | v1 | v2 |
|---|---|---|
| H | Ø40 | **Ø44** (стенка у устья круглого паза 1,5 мм) |
| C | Ø56, 8 пазов (4 одинарных, 2 двойных, 1 тройной) | то же, пазы нового типа |
| O | Ø52, 2 одинарных (104,5°) + 1 двойной | то же, пазы нового типа |
| N | Ø52, 3 одинарных + паз заглушки + тройной | + **двойной паз** (sp²: 120° к одинарному T0, в плоскости с T0 и T1; фаза подобрана — HO–N=O собирается плоским) |
| Новые элементы | нет | **F, Cl, Na, K, Mg, Ca, S, P** (атомы, связи P=O и S=O; одинарные связи для них ещё не сделаны) |
| Заглушка неподелённой пары | ключ v1 | круглый ключ v2, подходит в любой одинарный паз |

## 3. Связи

| | v1 | v2 |
|---|---|---|
| Набор | C–C, C–H, C–O, C–N, N–H, O–H, H–H; C=C, C=O, O=O; C≡C, C≡N, N≡N | то же + **N=O** (1,15 Å), P=O, S=O |
| Длина | реальная для каждой пары | реальная + **универсальные U1** (79 мм, для C–C и C–O) и **U2** (43 мм, для C–H, N–H, O–H) — одна деталь на несколько пар, погрешность 3–6 % |
| Маркировка | нет (надписи сняты) | **длина в ангстремах** выгравирована на боку с двух сторон («1.54 Å»); U1/U2 без надписи |
| Гибкость | жёсткие стержни Ø12 | одинарные — с гибким участком на 70 % длины, два финальных варианта: **spring** (решётка-стент: 5 лент правой спирали + 5 тонких встречных на сердечнике Ø3) и **slots** (трубка с прорезями + внутренняя 3-заходная спираль на сердечнике Ø4). Двойные и тройные остались жёсткими; есть и жёсткая версия одинарных |
| Печать | стоя, PETG | стоя, PETG, без поддержек; гибкие можно и лёжа с поддержками (прочнее на изгиб) |

## 5. Печать

- v1: атомы без поддержек; у углерода островок ≤1 мм².
- v2: у углерода и у азота (с двойным пазом) островок до 10–11 мм² в устье паза, смотрящего вниз → включать **Enable support + tree(auto) + Support critical regions only**. Связи — стоя, без поддержек.

## 6. Что мешает релизу v2

Spring и slots оба входят в набор. Выбор одного варианта релиз не блокирует: его можно сделать позже, либо в финальном наборе останутся обе версии.

1. Проверка в пластике: натяг губы 0,3 мм (`peg_lip`), удержание бугорков (`peg_bump`), исключение Рёло 15 ↔ круглый паз.
2. Рендер STL и булева сборка двадцати новых связей и первых молекул (`pipeline/rebuild_v2.py`). Описания уже в исходниках.
3. Тем же скриптом — README, пластины и BOM двадцати молекул v1.0. Конвейер уже смотрит в папки v2.

## 7. Что остаётся общим ограничением

- Азот с одинарными связями всегда пирамидальный (плоский амидный N не реализован).
- Нет двойной связи N=N и элементов за пределами перечисленных.
- Пазы углерода не подписаны (различаются по описанию в README).
