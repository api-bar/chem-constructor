# v2.0-beta5 — гибкие связи: два финальных варианта (spring, slots) + связь NO

Решение: из четырёх кандидатов оставлены **spring** и **slots**, оба переработаны. Гибкий участок — 70 % длины стержня,
45°-пробки на концах, печать **стоя** без поддержек (все детали герметичны, одно тело, 0 островов).
Гибкими сделаны только **одинарные** связи; двойные и тройные — жёсткие (одинаковы в обоих вариантах).

| Вариант | Устройство | Почему прочнее |
|---|---|---|
| **spring** | тонкий сердечник Ø3 + **5 лент 2×2** по правой спирали 45° + **5 тонких лент 1,4×1,4 по левой спирали** на том же радиусе; ленты сплавлены в перекрестьях — решётчатая трубка Ø12 (как стент) | излом требует разрыва нескольких лент сразу; нагрузка расходится по всей решётке; сердечник держит длину |
| **slots** | трубка Ø12, стенка 1,5, кольцевые прорези 150° в шахматном порядке (концы прорезей скруглены) + **внутри** 3-заходная спираль 1,6×1,6 вокруг сердечника Ø4, соединённая с трубкой только через торцевые пробки | внутренняя спираль задаёт плавную кривизну (нет излома в одной прорези) и держит растяжение; при трещине перемычки связь не распадается |

Параметры в `chem_constructor.scad`: `FLEX = "spring" | "slots"`, `sp_*` (spring), `sl_*` и `flex_wall`, `flex_pitch` (slots).

## Связь NO
У азота нет двойного паза (3 одинарных, паз заглушки, тройной), поэтому N=O обычным ключом не собрать.
Порядок связи в NO — 2,5, и связь сделана «гибридной»: **у азота ключ-Рёло (в тройной паз), у кислорода линза (в двойной паз)**, длина 1,15 Å.
Новый атом печатать не нужно.
