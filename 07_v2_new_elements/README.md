## Что собирается
Реакция → нужные связи (✔ уже есть, ⧗ нужно сгенерировать; STL с радиусами атомов на концах):
- 2Na + Cl₂ → 2NaCl: Cl–Cl ⧗, Na–Cl ⧗
- HCl + NaOH → NaCl + H₂O: H–Cl ⧗, Na–O ⧗, O–H ✔
- H₂ + F₂ → 2HF: H–H ✔, F–F ⧗, H–F ⧗
- N₂ + 3H₂ → 2NH₃: N≡N ✔, H–H ✔, N–H ✔
- Mg + 2HCl → MgCl₂ + H₂: Mg–Cl ⧗
- Ca(OH)₂: Ca–O ⧗, O–H ✔
- H₂S: S–H ⧗; H₂SO₄: S–O ⧗, S=O ✔ (`stl/bond_SdO.stl`), O–H ✔; SO₂: 2×S=O ✔
- H₃PO₄: P–O ⧗, P=O ✔ (`stl/bond_PdO.stl`), O–H ✔; PH₃: P–H ⧗
- CH₃Cl: C–Cl ⧗; NF₃: N–F ⧗

## Проверено по STL
- 8 новых атомов: герметичны, по одному телу, 0 послойных островков.
- Одинарные пазы F, Cl, Na, K, Mg (2), Ca (2), S (2), P (3): ключ садится, остаток 0,00 мм³, вращение свободно.
- Двойные пазы: P=O (158°) 0,47 мм³; S=O в оба двойных паза S 0,47 и 0,68 мм³; кислородный конец обеих связей 0,60 мм³ — как у линзы кислорода в v2.
- Из этого набора ещё не собрана ни одна молекула целиком: нужны недостающие связи ⧗.

## Ограничения
1. **Металлы — ионные соединения.** Na–Cl, Ca–O в кристалле не имеют направленных связей; набор показывает формульную единицу «шарик–палочка» и длины пар в газовой фазе. Решётку поваренной соли из него не собрать.
2. **Углы S и P идеализированы** тетраэдром 109,5°: у H₂S реально 92°, у PH₃ 93,5°, у SO₂ 119°.
3. **Размеры не по шкале для лёгких элементов:** F ограничен снизу размером паза (Ø44), как водород.
4. **Не включены:** Br, I (копии Cl с другим радиусом), Al (3 одинарных на 120°), Fe, Cu, Zn (переменная валентность). Br, I, Al добавляются за час.
5. K (Ø80, 262 см³) — самая тяжёлая деталь набора.
